Privacy Policy

Chrome Bookmark Checker • Last updated: September 15, 2026

This Privacy Policy describes how the Chrome Bookmark Checker browser extension ("we", "our", or "the extension") handles user data.

1. Data Collection & Processing

Chrome Bookmark Checker is built with a strict privacy-first approach:

  • Zero Personal Data Collection: The extension does not collect, record, log, or sell any personal data, account information, or browsing history.
  • 100% Local Processing: All bookmark scanning, duplicate URL detection, and URL normalization run exclusively inside your local browser instance.
  • Direct Link Verification: When verifying whether a bookmark is alive or broken, the extension sends standard HTTP requests (HEAD / GET) directly from your browser to the bookmark's destination web server. No intermediary servers, third-party analytics, or proxies are used.
  • Local Preferences Only: Any state or configuration is stored on your device using Chrome's chrome.storage.local API and is never transmitted off your machine.

2. Permissions Justification

  • bookmarks: Required strictly to read your saved bookmark tree to identify dead links and duplicate URLs. The extension does not alter your bookmarks without your explicit action.
  • storage: Required solely to save scan progress and user preferences locally.
  • <all_urls>: Required to send HTTP verification requests to arbitrary web endpoints corresponding to your saved bookmarks to test link connectivity.

3. Third-Party Sharing

We do not sell, rent, monetize, or transmit any user data or bookmarks to third parties, advertising networks, or tracking services.

4. Single Purpose Compliance

The extension adheres strictly to the Google Chrome Web Store Single Purpose Policy: its sole function is to help users scan, validate, and clean up their saved browser bookmarks.
